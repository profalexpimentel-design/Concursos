1. Conjuntos Numéricos

Os números são organizados em conjuntos que se contêm uns nos outros. Conheça cada um:

🌿 Naturais (ℕ)

ℕ = {0, 1, 2, 3, 4, ...}

Números usados para contar. O ℕ* exclui o zero: ℕ* = {1, 2, 3, ...}.

🔢 Inteiros (ℤ)

ℤ = {..., −3, −2, −1, 0, 1, 2, 3, ...}

Naturais + seus negativos + o zero.

➗ Racionais (ℚ)

ℚ = {a/b | a ∈ ℤ e b ∈ ℤ*}

São os números que podem ser escritos como fração: inteiros, decimais exatos (0,5) e dízimas periódicas (0,333...).

🌀 Irracionais (𝕀)

São os números que não podem ser escritos como fração: decimais infinitos não periódicos, como √2, √3, π.

🌐 Reais (ℝ)

ℝ = ℚ ∪ 𝕀

Todo número real é racional ou irracional — nunca os dois ao mesmo tempo.

🎯 Dica do Prof: a hierarquia é ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ, e 𝕀 ⊂ ℝ com 𝕀 ∩ ℚ = ∅. Se o número vira fração (ou dízima com período), é racional. Se a decimal não repete nada, é irracional.

2. Racionais — Dízimas Periódicas

Uma dízima periódica é um decimal infinito em que um bloco de algarismos (o período) se repete. Toda dízima periódica é racional, pois tem fração geratriz.

Tipos de dízima

  • Simples: 0,333... (período 3) e 0,272727... (período 27).
  • Composta: 0,2666... (o "2" não repete; só o "6" é período).

Fração geratriz — método prático

Simples: numerador = período; denominador = tantos 9 quantos forem os algarismos do período.
0,444... = 4/9  •  0,2727... = 27/99 = 3/11
Composta: numerador = (número até o fim do período) − (parte que não repete); denominador = 9 (um para cada algarismo do período) seguido de 0 (um para cada algarismo da parte não periódica).
0,2666... = (26 − 2)/90 = 24/90 = 4/15

Com parte inteira

2,333... = (23 − 2)/9 = 21/9 = 7/3
🔑 Regra de ouro: no numerador, subtraia a parte que não se repete; no denominador, use 9 para o período e 0 para a parte fixa. Sempre simplifique no final!

3. Irracionais — Racionalização

Os irracionais não podem virar fração: são decimais infinitos sem período, como √2 ≈ 1,414213..., √3 ≈ 1,732050... e π ≈ 3,14159...

O que é racionalizar?

É eliminar a raiz do denominador de uma fração, multiplicando numerador e denominador pelo mesmo fator (não altera o valor).

Caso 1 — denominador é √a

Multiplique por √a / √a:
1/√2 = √2/2  •  2/√5 = 2√5/5

Caso 2 — denominador é a ± √b

Multiplique pelo conjugado (a ∓ √b), que elimina a raiz pela diferença de quadrados:
1/(√3 − 1) → (√3 + 1)/(√3 + 1) = (√3 + 1)/2
⚠️ Dica do Prof: racionalizar NÃO é "enfeite" — as bancas cobram isso dentro de outras questões (geometria, funções). Domine os dois casos e você nunca mais trava.

4. Exercícios Resolvidos

Exemplo 1 — Classificação

Classifique os números: 0,5 · √2 · 0,333... · −3 · π · 1/4

NúmeroConjuntoPor quê?
0,5ℚdecimal exato = 1/2
√2𝕀decimal infinito sem período
0,333...ℚdízima periódica = 1/3
−3ℤ ⊂ ℚinteiro
π𝕀não vira fração
1/4ℚfração = 0,25

Exemplo 2 — Geratriz simples

Encontre a fração geratriz de 0,272727...

Período 27 (2 algarismos) → 27/99 → simplificando por 9: 3/11

Exemplo 3 — Geratriz composta

Escreva 2,333... como fração irredutível.

(23 − 2)/9 = 21/9 → simplificando: 7/3

Exemplo 4 — Racionalização (caso 1)

Racionalize 2/√5.

2/√5 × √5/√5 = 2√5/5

Exemplo 5 — Racionalização (caso 2)

Racionalize 4/(√3 − 1).

4/(√3 − 1) × (√3 + 1)/(√3 + 1) = 4(√3 + 1)/(3 − 1) = 2(√3 + 1)

Qual dos números abaixo é irracional?

√4 = 2 (racional), 0,5 e 2,25 são decimais exatos, 0,333... é dízima periódica (1/3). Só √2 é irracional.

3.

Racionalizando 1/√3, obtemos:

CESGRANRIO • PROPRIEDADES

Questão 4

Se r é um número racional e m é um número irracional, é necessariamente verdadeiro que:

A soma de racional com irracional é sempre irracional. O produto só é irracional se r ≠ 0 (se r = 0, dá 0 racional) e m² pode ser racional (ex.: (√2)² = 2).
✅ Resposta: A) r + m é irracional

CLASSIFICAÇÃO NUMÉRICA

Questão 5

Considere as afirmações: I. Toda dízima periódica é um número racional. II. Toda raiz quadrada de número natural é irracional. III. O produto de um racional não nulo por um irracional é irracional. Está(ão) correta(s):

I verdadeira (dízima tem geratriz). II falsa: √4 = 2, que é racional. III verdadeira (ex.: 2 × √3 = 2√3).
✅ Resposta: C) I e III

8. Resumo do Capítulo

  • ✅ ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ: os conjuntos se contêm em cadeia.
  • ✅ Irracionais (𝕀): decimais infinitos sem período (√2, √3, π). 𝕀 ⊂ ℝ e 𝕀 ∩ ℚ = ∅.
  • ✅ Dízima simples: geratriz = período / 9...9 (0,444... = 4/9).
  • ✅ Dízima composta: (número até o período − parte fixa) / 9...9 0...0 (0,2666... = 24/90 = 4/15).
  • ✅ Racionalizar caso 1: denominador √a → multiplique por √a/√a (1/√2 = √2/2).
  • ✅ Racionalizar caso 2: denominador a ± √b → multiplique pelo conjugado (4/(√3 − 1) = 2(√3 + 1)).
  • ✅ Soma de racional com irracional é sempre irracional; produto só se o racional for não nulo.
🎯 Não esqueça: a Cesgranrio ama misturar fração geratriz com operações e racionalização dentro de outras questões. Treine os dois métodos até saírem no automático!
